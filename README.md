# FoodBlocks - Food Recipes Website

A responsive recipe website landing page built with HTML and Tailwind CSS.

**Live Demo:** [View Project](https://nusratjahankaifa.github.io/Food-Recipes-Website/)

## Features

- Responsive navigation bar with separate desktop and mobile menus
- Hero section with call-to-action buttons
- "Featured" recipe cards in a responsive grid (1, 3 or 4 columns depending on screen size)
- "Trending Now" section with image and headline layout
- Footer with contact information and legal links
- Hover effects and gradient buttons styled with Tailwind CSS utility classes

## Tech Stack

HTML5, Tailwind CSS

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/NusratJahanKaifa/Food-Recipes-Website.git
   ```
2. Open `index.html` in your browser.

No installation is needed, since `output.css` is already compiled.
